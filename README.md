# Gesture Draw 🎨

### Draw in the Air. Create Without Touch.

Gesture Draw is a real-time, touchless drawing application that allows users to create digital artwork using hand gestures through a webcam.

Built with Python, OpenCV and MediaPipe, it makes drawing interactive and fun using computer vision.

## ✨ Features

- Real-time hand tracking
- Touchless air drawing
- Gesture-based drawing controls
- Multiple drawing colors
- Eraser functionality
- Interactive browser-based drawing studio
- Save artwork as PNG
- Camera standby mode

## 🖐️ Gesture Controls

| Gesture | Action |
|:---:|---|
| ☝️ Index Finger | Draw |
| 🤏 Pinch (OK Sign) | Pause Drawing |
| ✊ Closed Fist | Erase |
| 🖐️ Open Palm | Change Color |
| 🤘 Sign of the Horns | Close Studio / Camera Standby |

## 🚀 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/codewithranikumari/AirCanvas-Pro.git
cd AirCanvas-Pro
```

**2. Create a virtual environment**

```bash
python -m venv .venv
```

**3. Activate the environment**

```bash
.venv\Scripts\activate
```

**4. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

**5. Run the application**

```bash
python main.py
```

Open your browser:

`http://127.0.0.1:8765/`
