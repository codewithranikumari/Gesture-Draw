Gesture Draw 🎨

Gesture Draw is a webcam-based air drawing application that lets you draw using simple hand gestures without touching your screen.

✨ Features

- Real-time hand tracking
- Air-based drawing
- Multiple gesture controls
- Interactive drawing studio
- Webcam integration

🖐️ Gesture Controls

Hand Gesture| Action
☝️ Index Finger| Draw
👌 OK / Pinch Sign| Pause Drawing
✊ Closed Fist| Erase
✋ Open Palm| Change Color
🤘 Sign of the Horns| Close Studio

🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- HTML
- CSS
- JavaScript
